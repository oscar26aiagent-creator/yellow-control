## Purpose

Checklist for future submission-readiness review of the Yellow-Control governance skill.

## Checklist

- SKILL.md has exactly one YAML frontmatter block.
- Frontmatter includes name, description, version, author, license, platforms, metadata tags.
- Skill behavior is concise and references docs for details.
- No credentials or secret material are present.
- No official endorsement claim is made.
- References point to maintained concept, register, and procedure docs.
- Output schema and defer/block behavior are explicit.
