# Governance Telemetry Procedure

This procedure defines minimum telemetry fields for governance decisions.

## Required telemetry

- action summary,
- classifications (ADAL/CDEL/ESAL/PCL),
- gate outcomes,
- final decision (allow/defer/block),
- rationale,
- approval reference,
- validation outcome.

## Steps

1. Capture pre-decision classification.
2. Record gate outcomes.
3. Record decision and rationale.
4. Record execution/validation results.
5. Store references to evidence artifacts.

## Quality checks

- entries are complete,
- entries avoid secret or private identifiers,
- decision logic is reproducible.
