# Secrets Handling Procedure

This procedure defines public-safe handling expectations for sensitive material.

## Principles

- never commit plaintext secrets,
- minimize secret exposure surface,
- separate public docs from restricted operational artifacts.

## Steps

1. Classify artifact confidentiality (PCL).
2. Remove credential-like material from public artifacts.
3. Replace with fictional placeholders.
4. Validate no secret markers remain.
5. Record redaction rationale.

## Defer and block conditions

Defer publication when classification is unresolved.
Block publication when secret material is detected.

## Public examples

Public examples must be clearly fictional and non-operational.
