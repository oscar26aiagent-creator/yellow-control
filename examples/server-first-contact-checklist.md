# Server First Contact Checklist

Fictional example checklist for governance-first onboarding.

- Confirm target exists in external access register.
- Confirm ADAL/CDEL/ESAL/PCL classification is present.
- Confirm approval scope is explicit.
- Create pre-change checkpoint.
- Perform reachability and identity checks only.
- Run read-only baseline audit only.
- Do not run arbitrary elevated commands.
- Do not use privileged container pathways unless explicitly approved.
- Record concise evidence summary.
- Defer or block if anything required is unknown.
